# Gita - Neevi's Version

Ask a question or describe a situation and get counsel drawn only from the Bhagavad Gita, with every verse shown in the original Sanskrit.

**Open it:** https://neevijain2101-bot.github.io/gita/

- Works in English, Hindi and Hinglish
- Offline guide with 21 common situations, plus a chapter-by-chapter reader of all 701 verses
- Optional personal answers if a visitor adds their own Anthropic API key (kept only in their browser)

Sanskrit text from the public-domain [gita/gita](https://github.com/gita/gita) dataset.
